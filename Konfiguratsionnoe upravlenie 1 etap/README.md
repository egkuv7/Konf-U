# Эмулятор командной оболочки UNIX-подобной ОС
Практическая работа №1 по дисциплине «Конфигурационное управление».
Вариант №15, группа ИКБО-50-25, РТУ МИРЭА — 2026.

Текущий этап: **Этап 1. REPL** — минимальный прототип с GUI-интерфейсом.

## 1. Общее описание

Проект представляет собой эмулятор командной оболочки UNIX-подобной ОС,
реализованный на языке Python с использованием графического интерфейса
на базе стандартной библиотеки `tkinter`.

На текущем этапе реализован минимальный прототип: диалог с пользователем
полностью поддерживается, команды ls и cd пока являются заглушками,
которые выводят своё имя и аргументы.

### Реализованные возможности

- GUI-интерфейс с историей ввода-вывода.
- Заголовок окна формируется на основе реальных данных ОС:
  `Эмулятор - [username@hostname]`.
- Парсер команд с поддержкой одинарных и двойных кавычек.
- Команды-заглушки ls, cd.
- Команда exit для закрытия окна.
- Обработка ошибок: неизвестная команда, незакрытая кавычка,
  пустой ввод.

### Технологии

- Python 3
- Стандартная библиотека tkinter
- Сторонние библиотеки **не используются**

## 2. Описание всех функций и настроек

### 2.1. Параметры командной строки

На Этапе 1 параметры командной строки **не используются**.
Они появятся на Этапе 2.

### 2.2. Встроенные команды

|Команда| Синтаксис   | Описание                            |
|-------|-------------|-------------------------------------|
| ls    | ls [args]   | Заглушка: печатает ls: [args].      |
| cd    | cd [args]   | Заглушка: печатает cd: [args].      |
| exit  | exit        | Закрывает окно эмулятора.           |

### 2.3. Основные функции модуля `src/main.py`

|Функция / объект| Назначение                                                |
|----------------|-----------------------------------------------------------|
| parse(raw)     | Разбор строки на команду и аргументы, поддержка кавычек.  |
| cmd_ls(args)   | Заглушка команды ls.                                      |
| cmd_cd(args)   | Заглушка команды cd.                                      |
| execute(raw)   | Диспетчер: маршрутизация по имени команды.                |
| go(event)      | Обработчик нажатия кнопки Go и клавиши Enter.             |

### 2.4. Обработка ошибок

| Ситуация            | Сообщение                                        |
|---------------------|--------------------------------------------------|
| Неизвестная команда | Ошибка: неизвестная команда '<имя>'              |
| Незакрытая кавычка  | Ошибка парсинга: незакрытая кавычка              |
| Пустой ввод         | (ничего не происходит, команда игнорируется)     |

## 3. Описание команд для сборки проекта и запуска тестов

### 3.1. Требования

- Python 3.10+
- Библиотека `tkinter` (входит в стандартную поставку Python;
  в Linux может потребоваться пакет `python3-tk`)

Сборка не требуется — используются только стандартные модули Python.

### 3.2. Запуск

python src/main.py

### 3.3. Запуск тестов

На Этапе 1 автоматические тесты не предусмотрены.
Проверка выполняется вручную по примерам из раздела 4.

## 4. Примеры использования

### 4.1. Запуск приложения

```bash
python src/main.py
```

Откроется окно с чёрным фоном, полем ввода, кнопкой `Go` и историей
команд. Введите команду и нажмите `Go` или `Enter`.

### 4.2. Заглушки `ls` и `cd`

```
> ls /home
ls: ['/home']

> cd "my dir"
cd: ['my dir']

> ls 'a b' c
ls: ['a b', 'c']
```

### 4.3. Обработка ошибок

```
> unknown
Ошибка: неизвестная команда 'unknown'

> ls "abc
Ошибка парсинга: незакрытая кавычка
```

### 4.4. Завершение работы

```
> exit
```

Окно эмулятора закрывается.
