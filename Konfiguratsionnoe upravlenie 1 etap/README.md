---

## 1. Общее описание

Проект представляет собой эмулятор командной оболочки UNIX-подобной ОС, реализованный на языке Python с использованием графического интерфейса на базе стандартной библиотеки `tkinter`.

На текущем этапе реализованы:

- минимальный прототип (Этап 1): диалог с пользователем, заглушки `ls`, `cd`;
- конфигурация (Этап 2): параметры командной строки, стартовый скрипт, отладочный вывод параметров при запуске.

### Реализованные возможности

- GUI-интерфейс с историей ввода-вывода.
- Заголовок окна формируется на основе реальных данных ОС: `Эмулятор - [username@hostname]`.
- Парсер команд с поддержкой одинарных и двойных кавычек.
- Команды-заглушки `ls`, `cd`.
- Команда `exit` для закрытия окна.
- Параметры командной строки: `--vfs`/`-v`, `--script`/`-s`.
- Выполнение стартового скрипта с поддержкой комментариев.
- Отладочный вывод параметров при запуске.
- Обработка ошибок: неизвестная команда, незакрытая кавычка, пустой ввод, ошибки стартового скрипта.

### Технологии

- Python 3
- Стандартная библиотека `tkinter`
- Сторонние библиотеки **не используются**

## 2. Описание всех функций и настроек

### 2.1. Параметры командной строки

| Параметр          | Краткая форма | Описание                              |
|-------------------|---------------|---------------------------------------|
| `--vfs <path>`    | `-v <path>`   | Путь к физическому расположению VFS.  |
| `--script <path>` | `-s <path>`   | Путь к стартовому скрипту.            |

### 2.2. Встроенные команды

| Команда | Синтаксис  | Описание                        |
|---------|------------|---------------------------------|
| `ls`    | `ls [args]`| Заглушка: печатает `ls: [args]`.|
| `cd`    | `cd [args]`| Заглушка: печатает `cd: [args]`.|
| `exit`  | `exit`     | Закрывает окно эмулятора.       |

### 2.3. Основные функции модуля `src/main.py`

| Функция / объект | Назначение                                               |
|------------------|----------------------------------------------------------|
| `parse_argv()`   | Разбор аргументов командной строки.                      |
| `parse(raw)`     | Разбор строки на команду и аргументы, поддержка кавычек. |
| `cmd_ls(args)`   | Заглушка команды `ls`.                                   |
| `cmd_cd(args)`   | Заглушка команды `cd`.                                   |
| `execute(raw)`   | Диспетчер: маршрутизация по имени команды.               |
| `run_script(path)`| Выполнение стартового скрипта.                          |
| `dump_params()`  | Отладочный вывод параметров при запуске.                 |
| `go(event)`      | Обработчик нажатия кнопки `Go` и клавиши `Enter`.        |

### 2.4. Обработка ошибок

| Ситуация                    | Сообщение                                    |
|-----------------------------|----------------------------------------------|
| Неизвестная команда         | Ошибка: неизвестная команда '<имя>'          |
| Незакрытая кавычка          | Ошибка парсинга: незакрытая кавычка          |
| Пустой ввод                 | (ничего не происходит, команда игнорируется) |
| Стартовый скрипт не найден  | Ошибка: стартовый скрипт не найден: <путь>   |
| Ошибка чтения скрипта       | Ошибка чтения скрипта: <сообщение>           |

## 3. Описание команд для сборки проекта и запуска тестов

### 3.1. Требования

- Python 3
- Библиотека `tkinter` (входит в стандартную поставку Python; в Linux может потребоваться пакет `python3-tk`)

Сборка не требуется — используются только стандартные модули Python.

### 3.2. Запуск

Без параметров:

```bash
python src/main.py
```

С параметрами:

```bash
python src/main.py --vfs ./vfs_data --script ./scripts/start_script.txt
```

С краткими формами:

```bash
python src/main.py -v ./vfs_data -s ./scripts/start_script.txt
```

### 3.3. Запуск тестов

Автоматические тесты на данном этапе не предусмотрены.
Для ручного тестирования используйте скрипты:

- Linux/macOS: `bash scripts/run_stage2.sh`
- Windows: `scripts\run_stage2.bat`

## 4. Примеры использования

### 4.1. Запуск приложения

```bash
python src/main.py
```

Откроется окно с чёрным фоном, полем ввода, кнопкой `Go` и историей команд. Введите команду и нажмите `Go` или `Enter`.

### 4.2. Заглушки `ls` и `cd`

```
> ls /home
ls: ['/home']

> cd "my dir"
cd: ['my dir']

> ls 'a b' c
ls: ['a b', 'c']
```

### 4.3. Обработка ошибок

```
> unknown
Ошибка: неизвестная команда 'unknown'

> ls "abc
Ошибка парсинга: незакрытая кавычка
```

### 4.4. Завершение работы

```
> exit
```

Окно эмулятора закрывается.

### 4.5. Запуск со стартовым скриптом

```bash
python src/main.py --script ./scripts/start_script.txt
```

В истории отобразятся все команды из скрипта и их вывод.

### 4.6. Отладочный вывод параметров

При запуске с параметрами в истории появится блок:

```
=== Параметры эмулятора ===
VFS path:     ./vfs_data
Start script: ./scripts/start_script.txt
```
