# Этап 1. REPL — минимальный прототип

Документ описывает содержание первого этапа практической работы №1
(вариант №15). Основной код — в `src/main.py`.

---

## Цель этапа

Создать минимальный прототип эмулятора командной оболочки UNIX-подобной
ОС. Большинство функций пока представляют собой заглушки, но диалог
с пользователем уже поддерживается.

Согласно заданию (п. 1–7 варианта №15), на этом этапе требовалось:

1. Реализовать приложение в форме графического интерфейса (GUI).
2. Формировать заголовок окна на основе реальных данных ОС.
3. Реализовать парсер, корректно обрабатывающий аргументы в кавычках.
4. Сообщать об ошибках выполнения команд.
5. Реализовать команды-заглушки `ls`, `cd`.
6. Реализовать команду `exit`.
7. Продемонстрировать работу прототипа в интерактивном режиме.

---

## Что реализовано

- **GUI-интерфейс** на библиотеке `tkinter`.
- **Заголовок окна** строится из реальных данных ОС:
  `Эмулятор - [username@hostname]`.
  - `username` — из `getpass.getuser()`;
  - `hostname` — из `socket.gethostname()`.
- **Парсер командной строки** (функция `parse`) с поддержкой:
  - одинарных кавычек `'...'`;
  - двойных кавычек `"..."`;
  - обнаружения незакрытой кавычки.
- **Команды-заглушки** `ls` и `cd`, выводящие своё имя и аргументы.
- **Команда `exit`**, закрывающая окно эмулятора.
- **Обработка ошибок**:
  - неизвестная команда;
  - незакрытая кавычка;
  - пустой ввод.
- **История диалога**: для каждой команды в окне отображается
  и ввод, и вывод (имитация терминала).
- **Демонстрационный блок** в начале истории — примеры всех
  реализованных возможностей.

## Список команд

| Команда | Синтаксис    | Описание                              |
|---------|--------------|---------------------------------------|
| `ls`    | `ls [args]`  | Заглушка: печатает `ls: [args]`.      |
| `cd`    | `cd [args]`  | Заглушка: печатает `cd: [args]`.      |
| `exit`  | `exit`       | Закрывает окно эмулятора.             |

---

## Основные функции

| Функция        | Назначение                                                     |
|----------------|----------------------------------------------------------------|
| `parse(raw)`   | Разбор строки на команду и аргументы с поддержкой кавычек.     |
| `cmd_ls(args)` | Заглушка команды `ls`.                                         |
| `cmd_cd(args)` | Заглушка команды `cd`.                                         |
| `execute(raw)` | Диспетчер: маршрутизация по имени команды.                     |
| `go(event)`    | Обработчик нажатия кнопки `Go` и клавиши `Enter`.              |

## Примеры работы

### Заглушки `ls`, `cd`

```
> ls /home
ls: ['/home']

> cd "my dir"
cd: ['my dir']

> ls 'a b' c
ls: ['a b', 'c']
```

### Обработка ошибок

```
> unknown
Ошибка: неизвестная команда 'unknown'

> ls "abc
Ошибка парсинга: незакрытая кавычка
```

### Завершение работы

```
> exit
```

Окно эмулятора закрывается.

---

## Как запустить

Требования:

- Python 3.10+
- `tkinter` (входит в стандартную поставку; в Linux может
  понадобиться пакет `python3-tk`)

Запуск:

```bash
python src/main.py
```
