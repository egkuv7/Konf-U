# Этап 2. Конфигурация

Документ описывает содержание второго этапа практической работы №1 (вариант №15). Основной код — в `src/main.py`.

---

## Цель этапа

Сделать эмулятор настраиваемым, то есть поддержать ввод параметров пользователя в приложение. Организовать отладочный вывод всех заданных параметров при запуске эмулятора.

---

## Требования (из задания)

1. **Параметры командной строки:**
   - Путь к физическому расположению VFS.
   - Путь к стартовому скрипту.

2. **Стартовый скрипт** для выполнения команд эмулятора:
   - поддерживает комментарии (синтаксис `#`);
   - при выполнении на экране отображается как ввод, так и вывод, имитируя диалог с пользователем.

3. **Сообщить об ошибке** во время исполнения стартового скрипта.

4. **Создать несколько скриптов реальной ОС**, в которой выполняется эмулятор. Включить в каждый скрипт вызовы эмулятора для тестирования всех поддерживаемых параметров командной строки.

5. Результат выполнения этапа сохранить в репозиторий стандартно оформленным коммитом.

---

## Что реализовано

### 2.1. Параметры командной строки

| Параметр          | Краткая форма | Описание                              |
|-------------------|---------------|---------------------------------------|
| `--vfs <path>`    | `-v <path>`   | Путь к физическому расположению VFS.  |
| `--script <path>` | `-s <path>`   | Путь к стартовому скрипту.            |

Разбор аргументов выполняет функция `parse_argv()`.

### 2.2. Стартовый скрипт

- Выполняется функцией `run_script(path)`.
- Поддерживает комментарии: строки, начинающиеся с `#`, игнорируются.
- Пустые строки игнорируются.
- Для каждой команды на экран выводится и ввод, и вывод (имитация диалога с пользователем).
- Если файл не найден — выводится сообщение об ошибке.
- Если при чтении возникает ошибка ввода-вывода — выводится сообщение.

### 2.3. Отладочный вывод при запуске

Функция `dump_params()` вызывается при старте приложения и выводит все заданные параметры в область истории. Это соответствует цели этапа: «организовать отладочный вывод всех заданных параметров при запуске эмулятора».

## Список команд (обновлённый)

| Команда    | Синтаксис      | Описание                                    |
|------------|----------------|---------------------------------------------|
| `ls`       | `ls [args]`    | Заглушка: печатает `ls: [args]`.            |
| `cd`       | `cd [args]`    | Заглушка: печатает `cd: [args]`.            |
| `exit`     | `exit`         | Закрывает окно эмулятора.                   |

---

## Основные функции

| Функция             | Назначение                                                      |
|---------------------|-----------------------------------------------------------------|
| `parse_argv()`      | Разбор аргументов командной строки.                             |
| `parse(raw)`        | Разбор строки на команду и аргументы с поддержкой кавычек.      |
| `cmd_ls(args)`      | Заглушка команды `ls`.                                          |
| `cmd_cd(args)`      | Заглушка команды `cd`.                                          |
| `execute(raw)`      | Диспетчер: маршрутизация по имени команды.                      |
| `run_script(path)`  | Выполнение стартового скрипта.                                  |
| `dump_params()`     | Отладочный вывод параметров при запуске.                        |
| `go(event)`         | Обработчик нажатия кнопки `Go` и клавиши `Enter`.               |

## Примеры работы

### Запуск с параметрами

```bash
python src/main.py --vfs ./vfs_data --script ./scripts/start_script.txt
```

### Отладочный вывод при запуске

```
=== Параметры эмулятора ===
VFS path:     ./vfs_data
Start script: ./scripts/start_script.txt
```

### Стартовый скрипт

Файл `scripts/start_script.txt`:

```
# Это комментарий
ls /home
cd /tmp
# Пример ошибки
unknown_command
exit
```

При запуске эмулятора с этим скриптом в истории отобразятся все команды и их вывод.

---

## Как запустить

Требования:

- Python 3
- `tkinter`

Запуск без параметров:

```bash
python src/main.py
```

Запуск с параметрами:

```bash
python src/main.py --vfs ./vfs_data --script ./scripts/start_script.txt
```
